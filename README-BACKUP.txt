LUZ EM CASA — CÓPIA DE SEGURANÇA (BACKUP)
Data: 26 de novembro de 2026

O QUE É ISTO?
Uma cópia completa da app «Luz em Casa»: a app em si e, o mais
importante, os TEUS DADOS — as casas, os consumos mensais desde 2023,
as faturas arquivadas (com os PDF) e a lista de comercializadores com
as ofertas.

COMO GUARDAR
Guarda este ficheiro no teu computador, numa pen ou no teu Google
Drive / OneDrive — como guardas qualquer outro ficheiro.

COMO REPOR TUDO
Se algum dia quiseres voltar à app: abre uma conversa nova com o Z.ai,
envia este ficheiro zip e pede «repor a app Luz em Casa tal como
estava». Casas, gráficos e faturas voltam todas.

E O GITHUB, PARA QUE SERVE?
O GitHub é um «arquivo online de código», usado por programadores.
NÃO é preciso para usares a app. Só faz sentido se um dia quiseres
pôr a app na internet a funcionar para sempre, a partir de qualquer
telemóvel — nesse caso cria-se uma conta no GitHub e o código fica lá
guardado, e a app aloja-se num serviço que a mantém ligada dia e
noite. O teu zip já serve perfeitamente como cópia de segurança.

O QUE VAI DENTRO DO ZIP
- db/            → os teus dados (casas, consumos, faturas e os PDF)
- src/           → o código da app
- prisma/        → a «planta» da base de dados
- scripts/       → ferramentas auxiliares
- package.json e afins → as instruções para a app correr
